## Overview

CS Workspace is a full-stack application designed to organize customer follow-ups, campaigns, technical support requests, and day-to-day operations for Customer Success professionals.

This repository is a **public project showcase**. The application source code is maintained in a **separate private repository**. The code published here contains only the static presentation page—not the application's Next.js, Python, or database implementation.

## Key features

- **Executive dashboard:** workload indicators, priorities, and recent activity.
- **Task management:** statuses, priorities, categories, optional deadlines, notes, and filters.
- **Kanban board:** drag-and-drop across five workflow states.
- **Client organization:** client profiles and customer-specific activity.
- **Calendar:** monthly view of due dates and follow-ups.
- **Reporting:** workload distribution and completion metrics.
- **Account security:** authenticated sessions, password hashing, and user data isolation.
- **Dark themes:** Midnight and Graphite, with customizable accent colors.
